# NuraCare Mobile

The mobile app is built with **Expo** and **React Native**.

## Tech Stack
- Framework: Expo + React Native
- Routing: Expo Router
- State Management: Zustand
- Storage/Caching: MMKV
- Database/Auth: Supabase

## Key Features
- **Offline First**: Data is cached locally using MMKV and synced in the background.
- **Tabbed Interface**: Organized into Home, Chat, Wellness, Checkups, Discovery, and Profile.
